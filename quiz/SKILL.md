## What I do

- Review the changes made for the requested feature/bugfix
- Ask the user an appropriate number of questions to make sure that they understand the implementation of the feature/bugfix. You should also quiz about certain uses of the programming language itself if it is key to the implementation. Use a questions tool if you have access to one. Keep the number of questions to 10 or less.
- Make sure that you randomize the placement of correct answers when doing multiple choice (e.g. do not always put the correct answer as the first choice)
- If the user gets a question wrong, correct them and explain why.
- After the quiz is over, ask the user if they have any other questions about the implementation.

## When to use me

Use this when the user tells you to use the quiz skill.
