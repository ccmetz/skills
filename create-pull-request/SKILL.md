## What I do

- Check to see if the user has the GitHub CLI installed. If not, prompt them to install it if they wish.
- Open a pull request on GitHub using the GitHub CLI. The PR title should be in the format `Short description of the feature`. Make sure to add a thorough description to the PR as well and include a line at the bottom that says "Initial PR generated by <model_name>". If there is some sort of auth error when creating the PR through the CLI, notify the user and ask them to login. Once they have logged in, try creating the PR again.

## When to use me

Use when the user asks me to create a pull request for the feature or bug fix being worked on
